# Contribuindo

Obrigado pelo interesse. Contribution guidelines curtas e diretas:

## Como contribuir

1. Abra uma issue descrevendo o problema antes de codificar, para alinhamento.
2. Crie um branch descritivo a partir de `main`.
3. Mantenha commits pequenos e com mensagens no formato Conventional Commits
   (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`).
4. Rode a CI localmente antes de abrir o PR.
5. Abra o Pull Request preenchendo o template.

## Revisao

Todo PR precisa de pelo menos uma aprovacao antes do merge. Nao faca merge do
proprio PR sem revisao de outra pessoa.

## Escopo

Este e um repositorio pessoal de experimenting. Mudancas que nao mantenham o
escopo documentado no README podem ser recusadas sem discricao.
