# badges

Progresso em badges do GitHub. Registrado aqui para não perder o histórico.

## Legítimo — depende de uso real

| Badge | Como se ganha |
| --- | --- |
| Pull Shark | PRs mergeados (2 / 16 / 128 por nível) |
| Pair Extraordinaire | PR co-autorado (2 / 16 / 128) |
| Public Sponsor | Patrocinando alguém via GitHub Sponsors |
| Star Gazer | Repositório com mais de 16 estrelas |
| Galaxy Brain | Resposta aceita em Discussions |
| Quickdraw | Issue fechada em até 5 min da criação |
| YOLO | PR mergeado sem revisão |
| Trailblazer | Adotou projeto antes da release 1.0 |
| Arctic Code Vault | Contribuiu com código em 2020/2021 |

## Como este repositório ajuda

- `tools/badges.py` reporta o que falta em descrição, topics, licença, README
  e release — esses itens sustentam Pull Shark e-repo credibility.
- CI real, testes e template de PR facilitam merge de verdade
  (Pull Shark) e revisões de terceiros (Pair Extraordinaire).

## Não automatizado — e por quê

YOLO e Quickdraw exigem comportamento anti-colaborativo (merge sem revisão,
fechar issue em 5 minutos). Fabricar isso com script é spam e viola as
Community Guidelines do GitHub. Arctic Code Vault, Galaxy Brain, Speaker Deck
e Trailblazer dependem de eventos históricos ou reconhecimento humano que não
podem ser falsificados.
